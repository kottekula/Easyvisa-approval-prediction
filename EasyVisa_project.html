EasyVisa Approval Prediction - Machine Learning Project¶

The goal of this project is to analyze visa application data and build a machine learning model that can predict whether a visa application will be approved or denied.

Problem statement¶

Companies apply for work visas for employees from different countries. The visa approval process depends on several factors such as education,experience,salary,job,training and region.

This project helps us to:

  • To Understand factors affecting visa approval.
  • Analyze applicant patterns.
  • Build a prediction model using machine learning.

Objective¶

  • To perform data analysis on visa applications.
  • To identify important factors affecting visa approval.
  • To build a machine learning model for prediction.
  • To help companies make better hiring.

In [95]:
def annual_wage(row):

    if row["unit_of_wage"] == "Hourly":
        return row["prevailing_wage"] * 2080

    elif row["unit_of_wage"] == "Weekly":
        return row["prevailing_wage"] * 52

    elif row["unit_of_wage"] == "Monthly":
        return row["prevailing_wage"] * 12

    else:
        return row["prevailing_wage"]

df["annual_wage"] = df.apply(annual_wage, axis=1)

Final Model Selection¶

Among all the models tested, Random Forest and AdaBoost achieved the highest performance. After hyperparameter tuning, the Random Forest model was selected as the final model because of its strong accuracy and ability to handle complex patterns in the data.

Conclusion¶

This project analyzed the EasyVisa dataset and developed multiple machine learning models to predict visa approval status. Different factors such as education level, job experience, annual wage, company age, and employment type were studied during the analysis. Among the models tested, Random Forest and AdaBoost produced the highest accuracy. Hyperparameter tuning further improved the Random Forest model, making it the final selected model. The project demonstrates how machine learning can be used to understand visa approval patterns and support decision-making for employers.

Key Insights¶

  • Applicants with higher education levels generally showed better approval chances.
  • Candidates with prior job experience received more approvals.
  • Annual wage and company-related factors influenced visa approval decisions.
  • Random Forest and AdaBoost achieved the highest model accuracy among the models tested.
  • Full-time positions were associated with higher approval rates.

Recommendations¶

  • Employers should prioritize candidates with relevant work experience and higher education qualifications.
  • Offering competitive wages may improve visa approval chances.
  • Full-time employment opportunities should be encouraged whenever possible.
  • Predictive models such as Random Forest can support visa-related decision making.
  • Additional applicant and employer information may further improve prediction accuracy.
